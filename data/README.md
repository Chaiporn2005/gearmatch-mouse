# Data provenance

21 mouse SKUs, 3 manufacturers. Official pages were read on 2026-10-24. Prices are recorded USD references: original/reference amounts displayed with offers where available, otherwise displayed US prices. Razer Cobra alone uses explicitly dated 2023-06-29 launch MSRP. These are not all current prices or all MSRP. Taxes, shipping, stock and Thai retail conversion are outside scope. Offers are recorded separately and never used as budget references.

Variant names prevent mixing a low variant's price with flagship sensor claims. null means unverified, not false. Charging alone never establishes wired data support. Pebble's compatible Bolt receiver is sold separately. Manufacturer weights differ in cable/battery inclusion and may have tolerances; see product notes. M3 8K and M4 4K weight are conservatively null due unclear variant attribution. Handedness is null unless explicitly established. Maximum polling applies to documented wired/2.4-GHz modes, not automatically Bluetooth.

use_cases are project-authored indexing tags, not independent benchmarks. features normalize manufacturer claims. No independent latency, comfort, reliability or medical-outcome evidence is asserted. This is a small convenience sample with brand and selection bias.

raw/manufacturer-notes.md contains original short factual paraphrases with citations, not source HTML archives. Manufacturers retain rights in their text, images, logos and trademarks. No open-content license is assumed. No images or long source passages are redistributed. The code license does not relicense third-party content.
