# Submission checklist

Q1 requires a verified public github.com repository URL. Local code and Git history are prepared; no placeholder should be submitted.

Q2 report: GearMatch-report.pdf,6 pages. It includes architecture, measured baseline/ablation/improvement, live smoke tests, observed failure and limitations.

Q3 requires a3-6 minute narrated recording URL or an accessible, working live application URL. A private owner-only Site is a preview until access for the instructor is established. A catalog-only page without a live class proxy is not a completed LLM demo.

Remaining publication actions must use the real verified repository and deployment URLs. Never commit API keys or upload .env. The class-proxy key must stay server-side.
